# Example Portfolio

A responsive personal portfolio website built using **HTML, CSS, and JavaScript** to showcase my work, skills, and projects.

## Features

- Responsive design
- Smooth scrolling and animations
- Modern UI/UX
- Project showcase
- Skills and experience section
- Contact section
- Optimized for desktop and mobile

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)

## Project Structure

```
.
├── assets/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Getting Started

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser or use the **Live Server** extension in VS Code.
